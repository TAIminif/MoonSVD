# MoonSVD

MoonSVD is a MoonBit library and command-line tool for inspecting and comparing
the memory-mapped register descriptions in Arm CMSIS-SVD files.

The input is a device description distributed with a vendor's device pack.
The library resolves register metadata and reports differences using the
described register addresses, widths, access rules, reset values and fields.

See the [Open-CMSIS-SVD specification](https://open-cmsis-pack.github.io/svd-spec/main/index.html).
